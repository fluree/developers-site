# PDF Chatbot

Minimal scaffold for a Retrieval-Augmented Generation (RAG) PDF chatbot built with Streamlit.

Structure: simple skeletons for PDF processing, OCR, embeddings, FAISS vector store, and RAG glue.

Run:

1. Install dependencies: `pip install -r requirements.txt`
2. Set `OPENAI_API_KEY` in `.env`
3. Start app: `streamlit run app.py`
