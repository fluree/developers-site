_Fluree Sense_ allows different types of Data Sources and can take Data in the form of CSV as well as Files and from RDBMS Tables. Currently, Fluree Sense can support the following Data Sources:

- Cloud Data Sources: Files Hosted on Azure or AWS

- Hadoop as Data Source: Files Hosted on HDFS

- RDBMS (Relational) Data Source: PostgreSQL, Microsoft SQL Server, Oracle or MySQL

- Snowflake Data Source

A user is allowed to choose the Data Source Type as the first step based on which the connection definition and other steps are completed. Let us begin with the Create Data Source flow and check out this step.

> **NOTE**: When you choose _Relational Database_ as the Database Type, you then pick which relational database you're connecting to — PostgreSQL, Microsoft SQL Server, Oracle or MySQL — from a set of radio buttons, in the same way you pick a sub-option for cloud storage. That choice determines the connection methods offered on the next screen, so it's worth getting right the first time.
