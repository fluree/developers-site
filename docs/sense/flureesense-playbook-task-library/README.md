# FlureeSense Practitioner Playbook — Docusaurus content package

This package contains the **Task Library** card content plus a sidebar definition, ready to drop
into a Docusaurus site.

## What's inside

```
README.md            ← this file
sidebars.js          ← autogenerated-sidebar config (replaces the default)
docs/
  intro.md           ← landing page
  conventions.md     ← Appendix A · conventions & resolved decisions
  task-library/
    foundation/      ← SET-1 … SET-4
    acquisition/     ← ACQ-0 … ACQ-5
    target-model/    ← MOD-1 … MOD-4
    mapping/         ← MAP-1 … MAP-4
    data-quality/    ← DQ-1 … DQ-5   (DQ-2 = Pending stub)
    normalization/   ← NRM-1 … NRM-7 (NRM-7 = Deferred stub)
    resolution/      ← RES-1 … RES-9
    publishing/      ← PUB-1, PUB-2
    operationalize/  ← PRD-1 … PRD-9 (PRD-7, PRD-9 = Pending detail)
    monitoring/      ← MON-1 … MON-4
```

The sidebar is **autogenerated** from the folder structure and the `_category_.json` files, so you
never hand-maintain a sidebar list — new cards appear automatically when their files are added.

## Deploy & preview (three steps)

```bash
# 1. Scaffold a fresh Docusaurus site (one time)
npx create-docusaurus@latest flureesense-playbook classic
cd flureesense-playbook

# 2. Copy this package's contents in, overwriting docs/ and sidebars.js
#    (from the unzipped package directory)
cp -r /path/to/this/package/docs/* docs/
cp /path/to/this/package/sidebars.js sidebars.js

# 3. Preview with live reload at http://localhost:3000
npm run start
```

To produce the static site for hosting: `npm run build` (output in `build/`).

## Notes

- You don't need Docusaurus to *read* the cards — every file is plain Markdown and renders in
  GitHub, VS Code preview, Obsidian, etc.
- `status:` front matter (`doc` / `pending` / `deferred`) is informational; Docusaurus ignores it.
- Capture feedback however you like (inline comments, a tracking sheet, GitHub issues) — the cards
  are independent files, so edits don't collide.
- **Status:** the Task Library is complete — all 10 sections (54 cards) plus the conventions
  appendix. Stubs (`DQ-2`, `NRM-7`, `PRD-7`, `PRD-9`) are intentionally minimal and flagged in
  Appendix A §A6; the Master Playbook, Roles/RACI, and Archetype-lens prose sections remain to be
  written on top of this library when you're ready.
